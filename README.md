C++ Calculator Program

📌 Description

This project is a simple menu-driven calculator written in C++.
It performs the four basic arithmetic operations: Addition, Subtraction, Multiplication, and Division.
This program was created as part of my IDE Program Development assignment.


---

✨ Features

Easy-to-use menu interface

Supports +, –, ×, ÷ operations

Handles invalid choices

Checks for division by zero

Beginner-friendly code



---

🛠 How to Run the Program

Using VS Code / Code::Blocks

1. Download or clone this repository


2. Open the file calculator.cpp in your IDE


3. Compile the program


4. Run the executable



Using Terminal / CMD

g++ calculator.cpp -o calculator
./calculator
